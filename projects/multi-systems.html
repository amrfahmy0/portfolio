Enterprise ERP & Web App

Multi Systems — Construction & Fit-Out Management ERP

A full-stack Enterprise Resource Planning web application engineered specifically for Egyptian construction contractors and interior fit-out firms, centralizing financial accounting, procurement, task scheduling, supervisor wages, and automated Arabic document generation.

Client / Domain Construction & Fit-Out Contractors (Egypt)
My Role Lead Full-Stack Architecture & Development
Tech Stack Next.js 16, React 19, Supabase (PostgreSQL), TypeScript
Project Status Proprietary / In Production

The Problem

In typical construction and finishing operations across Egypt, project managers rely on scattered spreadsheets, paper receipts, verbal agreements, and fragmented WhatsApp chats. This leads to critical operational bottlenecks:

  • Cash Flow Blindspots: Inability to reconcile client deposits against daily on-site procurement and overhead in real time.
  • Lost Receipts & Tax Discrepancies: Field supervisors purchase materials without preserving physical receipts, creating audit issues.
  • Labor Wage Chaos: Difficulty recording daily site attendance and fluctuating daily wages for supervisors and laborers.
  • Billing Confusion: Disputes between pre-construction estimates (Quotations / مقايسات تقديرية) and civil engineering progress claims (Payment Certificates / مستخلصات أعمال).

The Solution

Multi Systems eliminates operational silos entirely. It provides a unified, high-performance, RTL-first Arabic web interface where project managers track all financial inflows and outflows, manage on-site material purchases with automated Web Worker image compression, monitor phase-based construction milestones, and generate formal engineering spreadsheets and PDF documents.

Key Features

📊 Executive Health Dashboard

Real-time company-wide KPIs computing Total Received from Clients, Total Project Expenses, and Company Net Liquidity across all ongoing sites.

💰 Multi-Stream Financial Ledger

Structured ledger tracking client installments, general overhead expenses, material procurement bills, and daily labor logs with paid/unpaid status safeguards.

📸 Web Worker Invoice Compression

Compresses 10MB+ site camera photos down to under 500KB in background browser threads before cloud upload, saving bandwidth while keeping text razor-sharp.

📅 11-Phase Milestone Scheduler

Tailored for architectural fit-out workflows (demolition, electrical, plumbing, plastering, tiling, carpentry, painting, handover) with multi-date selection.

📑 Styled Arabic Excel Engine

Server-side generation of pixel-perfect Microsoft Excel (.xlsx) quotations formatted to A4 portrait, RTL orientation, company branding, and formula-driven VAT (14%).

📜 Civil Engineering Payment Certificates

Implements standard Egyptian contractor progress billing (Previous, Current, Total Quantities, and % Execution) with instant vector PDF rendering.

Architecture & Data Flow

Client Layer (Next.js 16 + React 19 + TypeScript)
  ├── RTL Arabic Interface (Tailwind CSS + NextUI)
  ├── Form State & Validations (React Hook Form + Zod 4)
  └── Client-Side Image Compression (browser-image-compression Web Workers)
           │
           ▼
Server & Processing Layer (Vercel Edge & Server Actions)
  ├── Dynamic Project Routing (/projects/[id]/*)
  ├── Server-Side Excel Generator (ExcelJS — A4 RTL Corporate Format)
  ├── Dynamic PDF Generator (@react-pdf/renderer with Tajawal Arabic font)
  └── Automated Database Keep-Alive (Vercel Cron -> Supabase Ping)
           │
           ▼
Supabase BaaS (PostgreSQL 15 + Cloud Storage)
  ├── Relational Schema (Cascading FKs, Generated Total Columns, Custom Enums)
  └── Cloud Storage Bucket ('receipts' bucket for compressed invoices)
